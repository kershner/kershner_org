"The characters in the game do walk a little bit faster than a real human, but walking from one end of the continent to the other would be equivalent to really walking the length of Great Britain."

- Bruce Nesmith, Daggerfall's design leader From Trent Ward's Gamespot Daggerfall Preview, 1996

The Elder Scrolls II: Daggerfall was released in September 1996 and features one of the largest game worlds ever created. Using advanced procedural generation techniques, Daggerfall's developers were able to achieve an unprecedented scale that is still mind-blowing today.

Daggerwalk is a collection of technologies that live-streams a bot endlessly walking through the massive Iliac Bay, trudging through landscapes that few players would ever naturally see. Viewers can steer The Walker, interact with the game, complete quests, earn Renown, join guilds, and raise permanent monuments through Twitch chat. The Walker's journey and the community's progress are recorded on this website.

A humble small form factor Dell Optiplex PC runs Daggerwalk autonomously. It's programmed to boot up at a certain time each day, run the Daggerwalk scripts, and shut back down again on a timer. It handles the game's graphics, streaming, and running the Twitch bot comfortably - keeping a cool temperature for a stable operation many hours per day.

Game automation / Twitch bot

  • start_daggerwalk.bat
  • supervisor.py
  • twitch_bot.py

A Windows launcher starts a Python supervisor that coordinates OBS, Daggerfall Unity, game setup, and the Twitch bot. It waits for the game to become ready before enabling chat commands and automatically relaunches failed components. The bot handles viewer input, samples local game state, and synchronizes the journey and community progression with the kershner.org web server.
