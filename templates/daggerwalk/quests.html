Quests FAQ

How do quests and logs work?

Every 5 minutes the game sends a log of the current state to the server. Each log records the Walker's location, chat commands, and more. All three active quests are checked when a new log arrives.

What happens when a quest completes?

When a log matches a quest’s target POI, that quest is marked completed, all qualifying users are awarded, and a new quest immediately begins in the same slot.

How do I get XP?

Send a chat command while a quest is active. If your command appears in one of its logs, you receive that quest’s XP when it completes. One command can qualify you for multiple active quests.
